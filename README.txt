THE STAGE CAFE POS

Files:
- pos.html: POS page
- pos.css: design and layout
- pos.js: menu and POS functions

Run:
Keep all files in the same folder and open pos.html in Chrome.

GitHub:
Upload all four files to the same repository folder. Open pos.html to use the POS.

Limitations:
This starter version stores orders in the current browser/device only.
It does not yet include shared database sync, secure staff login, online payments,
or confirmed thermal-printer configuration. Verify all menu spellings and prices
against the printed menu before using it for real orders.
